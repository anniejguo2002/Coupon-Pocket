A lightweight Chrome extension that collects coupon codes advertised on shopping websites and automatically tries them at checkout.
Enable it for a store, browse as usual, and Coupon Pocket saves the codes it finds locally. At checkout, it tries saved codes and stops after the first confirmed success. You can also add codes manually.
- Automatic collection from store pages you visit
- Automatic coupon testing on supported checkout forms
- Per-site controls to choose where it runs
- Local storage with no accounts, tracking, or affiliate links
Prototype status: Coupon Pocket supports common English-language coupon fields. It doesn’t include a global coupon database, and compatibility with individual stores is still being tested.
